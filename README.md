# PostgreSQL 18 - Lecciones

Guía progresiva en español sobre PostgreSQL 18.

## Contenido

- Arquitectura, administración y monitorización
- JOIN, subconsultas y CTE
- Funciones de ventana y marcos
- Índices, EXPLAIN y rendimiento
- Roles, permisos, RLS y SECURITY DEFINER
- PL/pgSQL: funciones, procedimientos y triggers
- Funcionalidades específicas de PostgreSQL 18
- Concurrencia, bloqueos, colas de trabajo y SERIALIZABLE
- LISTEN/NOTIFY y transactional outbox
- Observabilidad con EXPLAIN MEMORY y pg_stat_statements

- `postgresql-18-lecciones.docx`: fuente editable para futuras actualizaciones.
